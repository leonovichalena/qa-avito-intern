# Тест-кейсы для микросервиса объявлений

## Общая информация
- **Base URL**: https://qa-internship.avito.com
- **Методы API**: 
  1. Создание объявления
  2. Получение объявления по ID
  3. Получение всех объявлений по seller ID
  4. Получение статистики по item ID

## Тест-кейсы

### 1. Тесты создания объявления

#### TC1: Успешное создание объявления с валидными данными
**Предусловия**: Нет

**Шаги**:
1. Отправить POST запрос на /api/items с валидными данными
2. Проверить ответ

**Ожидаемый результат**:
- Status code: 200
- В ответе присутствует поле: status
- Поле status содержит текст: "Сохранили объявление"

#### TC2: Создание объявления с невалидным seller_id (меньше диапазона)
**Предусловия**: Нет

**Шаги**:
1. Отправить POST запрос с seller_id = 10
2. Проверить ответ

**Ожидаемый результат**:
- Status code: 400

#### TC3: Создание объявления с невалидным seller_id (больше диапазона)
**Предусловия**: Нет

**Шаги**:
1. Отправить POST запрос с seller_id = 999999999999999
2. Проверить ответ

**Ожидаемый результат**:
- Status code: 400

#### TC4: Создание объявления без обязательных полей
**Предусловия**: Нет

**Шаги**:
1. Отправить POST запрос без поля "title"
2. Проверить ответ

**Ожидаемый результат**:
- Status code: 400

### 2. Тесты получения объявления по ID

#### TC5: Успешное получение существующего объявления
**Предусловия**: Создать тестовое объявление

**Шаги**:
1. Отправить GET запрос на /api/items/{item_id}
2. Проверить ответ

**Ожидаемый результат**:
- Status code: 200
- Данные в ответе соответствуют созданному объявлению

#### TC6: Получение несуществующего объявления
**Предусловия**: Нет

**Шаги**:
1. Отправить GET запрос с несуществующим item_id
2. Проверить ответ

**Ожидаемый результат**:
- Status code: 404

#### TC7: Получение объявления с невалидным ID
**Предусловия**: Нет

**Шаги**:
1. Отправить GET запрос с item_id = "invalid"
2. Проверить ответ

**Ожидаемый результат**:
- Status code: 400

### 3. Тесты получения объявлений по seller ID

#### TC8: Успешное получение объявлений существующего продавца
**Предусловия**: Создать несколько объявлений для одного seller_id

**Шаги**:
1. Отправить GET запрос на /api/sellers/{seller_id}/items
2. Проверить ответ

**Ожидаемый результат**:
- Status code: 200
- В ответе список всех созданных объявлений для данного seller_id

#### TC9: Получение объявлений несуществующего продавца
**Предусловия**: Нет

**Шаги**:
1. Отправить GET запрос с несуществующим seller_id
2. Проверить ответ

**Ожидаемый результат**:
- Status code: 404
- Пустой список в ответе

#### TC10: Получение объявлений с невалидным seller_id
**Предусловия**: Нет

**Шаги**:
1. Отправить GET запрос с seller_id = "invalid"
2. Проверить ответ

**Ожидаемый результат**:
- Status code: 400

### 4. Тесты получения статистики

#### TC11: Успешное получение статистики существующего объявления
**Предусловия**: Создать тестовое объявление

**Шаги**:
1. Отправить GET запрос на /api/items/{item_id}/stats
2. Проверить ответ

**Ожидаемый результат**:
- Status code: 200
- В ответе присутствует поле contacts

#### TC12: Получение статистики несуществующего объявления
**Предусловия**: Нет

**Шаги**:
1. Отправить GET запрос с несуществующим item_id
2. Проверить ответ

**Ожидаемый результат**:
- Status code: 404
