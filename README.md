## Задание 2.1 Тестирование API микросервиса объявлений Avito с использованием Playwright
Автоматизированные тесты для API микросервиса объявлений Avito с использованием Playwright.

Тестовая стратегия отдает приоритет скорости разработки в ущерб изоляции тестов. В рамках этого подхода:
- Тесты не являются атомарными и могут зависеть друг от друга.
- Наличие предварительно загруженных данных в базе данных является обязательным условием для работы некоторых тестовых сценариев.
- Жизненный цикл тестовых данных (создание и очистка) управляется не на уровне отдельных тестов, а в рамках общей тестовой среды.

*Примечание: Для промышленной эксплуатации проекта требуется переход к атомарным тестам с полным управлением данными.*

## Функциональности API
- Создание объявлений
- Получение объявления по ID  
- Получение всех объявлений по seller ID
- Получение статистики по item ID

## Предварительные требования
- Node.js 16+
- npm или yarn

## Установка и настройка

1. **Установите зависимости**

npm install

2. **Установите Playwright (если не установился автоматически)**

npx playwright install

3. **Запуск тестов**

npm test

4. **Просмотр отчета (если не запустился автоматически)**

npm run show-report
